Skills for Claude Desktop

Research you can cross‑examine.

UVRN Skills adds three tools to Claude Desktop. One checks a claim against independent sources and then re-checks its own work. One gives an honest probability for questions like who wins tonight. One tells you whether a number is really rising. Every answer ends with a chart.

Three skills

Each one answers in text and draws the chart.

Disagreement is the signal.

Install one or all three. After each run Claude asks whether you also want a Markdown report.

uvrn-factcheck

Cross-reference a claim

Claude gathers independent sources, counts each origin once, scores how well they agree, and flags the ones that contradict the rest. Then it re-checks itself: it re-reads the primary source, recomputes the figures and searches for evidence against the claim. The self-check result sits beside the score and never inside it.

Fact-check this claim and cross-reference it: humans only use 10% of their brains.
Cross-reference · research profile · real sources read 18 Oct 2026

Humans only use 10% of their brains

STABLE 3 of 3 independent origins call it a myth.

Three separate organizations, each counted once. The freshness window is set to 10 years because this is settled science. The score measures how sources agree and how recent they are. It does not prove anything on its own.

uvrn-forecast

Put a number on what happens next

Works from betting odds, a cited base rate, or a labeled judgment, and shows which one it used. Odds are stripped of the bookmaker's margin. If a quote is stale or there are too few comparable cases, you get the reason and no number. This is information, not betting advice.

Who is more likely to win tonight's game? Use current moneyline odds and show the basis.
Market-implied probability, sample odds −150 / +130

The ticks are three ways of removing the margin. The spread between them is shown, and it is not a confidence interval.

uvrn-trends

Find out if it is really going up

Give it a dated series. It reports the direction and size of the trend with a method that resists outliers, tests whether the trend is statistically detectable, flags odd points and projects forward with an interval. With too few points it says so instead of guessing.

How it stays honest

It says what the evidence shows and stops there.

UVRN is built around one rule: never claim more than the math proves. These skills keep it.

Tested against the originals

The math comes from the UVRN packages, and the tests check it.

What was checked

  • The odds and base-rate results match the golden vectors in the UVRN specification.
  • About 160 consensus cases, 400 scoring cases and 150 measurement cases give the same results as the published packages.
  • Decay curves and Brier scores match too.

How the tests were checked

  • The math was deliberately broken in several places to confirm that the tests fail when it is wrong.
  • Each skill is also run from a standalone copy to confirm it works with nothing else installed.

Known limits

  • Results are UVRN-style analyses. They are not signed UVRN receipts.
  • The trend analysis is new in this project and is not part of the UVRN packages.
  • The Claude Desktop steps depend on your app version.

Questions

Before you install.

What does it cost?

Nothing. It is open source under Apache-2.0. You need a Claude plan that supports skills and code execution.

Does it send my data anywhere?

The scripts run in your chat's code environment and make no network calls. Claude still searches and reads sources the way it normally does.

Can I trust the probabilities?

Treat them as estimates stated with their basis. One result cannot confirm or refute a probability. Calibration shows over many forecasts, and the forecast skill can keep a Brier track record of yours.

What is UVRN?

The Universal Verification Receipt Network, an open protocol for measuring and proving how independent evidence relates to a claim. These skills adapt its methods for use inside Claude. Learn more at uvrn.org ↗.
